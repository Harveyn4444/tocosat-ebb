# Test Code
Code developed for certain aspects of the TocoSat EBB are here. Each project focuses on addressing or developing one specific interface or functionality. Some examples use aspects from other examples, when and where they are sued should be noted and addressed in the project.


This code is developed for the Raspberry Pi C SDK. Where external libraries and drivers are used it will be stated and version controlled.

More detailed notes for each project will be included i the project's `README.md` file.

## Examples
